# AQ-50 in Georgian

An online Georgian-language version of the **Autism Spectrum Quotient (AQ-50)** — a 50-item self-report questionnaire that measures autistic traits in adults (Baron-Cohen et al., 2001).

**Live:** https://kandelucky.github.io/ka-aq-test/

## What it does

- 50 statements, each answered on a 4-point agree/disagree scale.
- Scoring follows the original AQ key: 1 point per item answered on the "autistic" side (0–50 total).
- Shows the total score, what the range means, and 5 subscales (10 items each): social skill, attention switching, attention to detail, communication, imagination.
- Runs entirely in the browser. No data is sent anywhere; progress is kept in `localStorage` until the test is finished.
- Results can be printed or saved as PDF.

## Notes

- The Georgian translation is unofficial.
- This is a screening tool, not a diagnosis.
- Single file (`index.html`), no build step, no dependencies.

## Reference

Baron-Cohen, S., Wheelwright, S., Skinner, R., Martin, J., & Clubley, E. (2001). The Autism-Spectrum Quotient (AQ). *Journal of Autism and Developmental Disorders*, 31(1), 5–17.
